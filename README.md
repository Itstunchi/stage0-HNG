# TaskFlow

A focused, responsive task management application built for HNG Cohort 15, Team Gannet.

## Overview

TaskFlow helps users capture, organize, complete, and manage everyday tasks without unnecessary complexity.

The application is built with native web technologies and requires no backend or external database.

## Features

- Create tasks
- Assign task priority
- Mark tasks as completed
- Delete tasks
- Search tasks
- Filter tasks
- Clear completed tasks
- Track completion progress
- Persist tasks using localStorage
- Responsive mobile-first interface
- Keyboard-accessible controls
- Reduced-motion support

## Technology

- HTML5
- CSS3
- Modern JavaScript (ES Modules)
- Browser localStorage
- Git

No frontend framework is required because the Stage 1 product scope does not justify framework-level complexity.
